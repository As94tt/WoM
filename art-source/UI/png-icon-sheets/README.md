# Raster icon source sheets (WoM v3)

The PNG images in this folder are original visual source sheets for the v2/v3 stone-and-gold icons. The individual production PNGs under `game/assets/ui/icons/` have been cropped and scaled from these sheets and include sRGB profiles.

**IMPORTANT:** Earlier SVG icons were removed because their visuals DID NOT match the revised PNG icons. Do not regenerate the production icons using an outdated SVG source. For source-to-icon mapping see `SOURCE_SHEET_MAP.csv`.

Icons should be used as image motifs; some interface-control icon crops have a decorative square backing baked into the image. Do not add redundant outer borders when using these assets. Validate legibility at native 20/40/48px display sizes, and verify the gameplay UI against actual project source before release.
